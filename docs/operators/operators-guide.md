## ⚠️ When Things Go Wrong

### Common Issues & Solutions

**Scanner Not Working?**
- Check battery level and restart device
- Clean scanner lens and try again
- Verify barcode quality and lighting
- Contact IT support if problem persists

**Can't Find Item Location?**
- Use location lookup function
- Check for similar location codes
- Verify item hasn't been moved
- Ask supervisor for assistance

**System Running Slowly?**
- Check WiFi connection strength
- Close and restart the app
- Clear app cache if available
- Report to IT for investigation

**Wrong Item Scanned?**
- Use "Cancel" or "Back" function
- Re-scan the correct item
- Report persistent scanning issues
- Document any recurring problems
